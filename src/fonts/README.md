# Fonts

Self-hosted from [google/fonts](https://github.com/google/fonts), converted to WOFF2. All three are licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

| File | Font | Used for |
|---|---|---|
| `young-serif.woff2` | Young Serif | Display headings |
| `hanken-grotesk-var.woff2` | Hanken Grotesk (variable) | Body text |
| `martian-mono-var.woff2` | Martian Mono (variable) | Addresses, hashes, stamp lettering |
